# Стек шторок: прототип анимации

Рабочий прототип анимации стека шторок по описанию из дизайн-системы Pole Mobile 2.0. Нужен, чтобы проверить параметры анимации в движении.

Без сборки и зависимостей: откройте `index.html` в браузере или включите GitHub Pages для репозитория.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | Демо-страница: телефон с двумя шторками и панель проверки |
| `styles.css` | Стили демо |
| `stack-sheets.js` | Сама анимация: токены, easing, правило следования первой шторки, жесты |
| `demo.js` | Наполнение демо и связь панели с компонентом |

## Как работает

Состояние сводится к одному числу `progress`: путь второй шторки, 0 за краем экрана, 1 на своём месте. Положение обеих шторок считается из него.

- Вторая шторка: `translateY((1 − progress) × travel)`.
- Первая шторка своей анимации не имеет. Пока `progress` идёт от 0.5 до 1, её scale линейно меняется 1 → 0.90, и она становится серой плашкой Stack. При закрытии то же в обратную сторону.
- Затемнение не анимируется и в компонент не входит.

## Токены

| Событие | Duration | Easing |
|---|---|---|
| Открытие | 360 мс, `slow-02` | `0, 0, 0.38, 0.9`, `productive-entrance` |
| Закрытие | 300 мс, `slow-01` | `0.2, 0, 1, 0.9`, `productive-exit` |
| Возврат после свайпа | 300 мс, `slow-01` | `0.22, 1.12, 0.37, 1.02`, `productive-bounce` |
| Первая шторка | нет, следует за второй | scale `1 → 0.90`, `scale-medium` |

Токены лежат в `StackSheets.TOKENS`, значения можно править в одном месте.

## Жесты

- Тап по первой шторке открывает вторую.
- Тап по второй шторке или по затемнению закрывает её.
- Свайп вниз: шторка идёт за пальцем без анимации. Отпустили до порога, шторка возвращается на место (bounce). После порога закрывается обычным закрытием.

## Использование

```html
<script src="stack-sheets.js"></script>
<script>
  var sheets = StackSheets.create({
    screen: document.getElementById('screen'),  // область затемнения
    first:  document.getElementById('s1'),      // transform-origin: 50% 0
    second: document.getElementById('s2'),
    plate:  document.getElementById('plate'),   // серый слой поверх первой шторки
    travel: 734                                  // путь второй шторки, px
  });
  sheets.open();
  sheets.close();
</script>
```

Другие методы: `setProgress(0..1)` для проверки по кадрам, `setSlow(k)` для замедления, `setThreshold(0..1)` для порога свайпа.

## Допущения

Этого нет в описании, значения выбраны в прототипе и их нужно подтвердить:

1. Плашка Stack: сдвиг первой шторки вверх на 20 px (`lift`), серый цвет, точка масштабирования — верхний центр.
2. «Путь» второй шторки: 0% за краем экрана, 100% на своём месте. Правило 50–100% линейное, без отдельного easing.
3. Порог закрытия при свайпе 30% высоты (`threshold`). Скорость жеста не учитывается.
4. У `productive-bounce` есть выброс за 100%: вторая шторка уходит чуть выше своего места, scale первой ограничен 0.90.
5. Прерывание анимации: новая стартует от текущего положения с полной длительностью токена.
6. Тап по второй шторке закрывает её, включая тап по строкам внутри.

Вопрос к описанию: подпись закрытия говорит «Как шторка, до 300px», хотя шторка выше 300 px. Закрытие взято 300 мс по фразе «быстрее открытия на один шаг».
